# eRent Platform

Ruby on Rails application for property rental management, including people,
properties, contracts, inspections, and contract amendments.

## Tech Stack

- Ruby on Rails
- Importmap + Stimulus
- Tailwind CSS
- SQLite (development default)

## Getting Started

1. Install dependencies:

	bundle install

2. Setup database:

	bin/rails db:setup

3. Start development server:

	bin/dev

4. Open in browser:

	http://localhost:3000

## Running Tests

bin/rails test

## Main Features

- People and user management
- Property management
- Contract lifecycle and amendments
- Property inspections
- Authentication and password recovery
